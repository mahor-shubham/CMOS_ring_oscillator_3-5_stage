# CMOS_ring_oscillator_3-5_stage

Design a three stage and five-Stage CMOS Ring Oscillator at 90nm, 45nm and 22nm technology. Keep 1V supply voltage (VDD) for all the technology nodes.
(a) Obtain the oscillation frequency for all the technology nodes.
(b) Obtain the propagation delay vs. channel length trend.
(c) power-delay product at each node.
